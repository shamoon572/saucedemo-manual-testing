# SauceDemo Manual Software Testing Project

## Application
SauceDemo / Swag Labs  
https://www.saucedemo.com/

## Testing
Manual Functional Web Application Testing

## Project Structure
- `01_Requirements/` – requirements and scope
- `02_Test_Plan/` – test strategy and plan
- `03_Test_Scenarios/` – high-level scenarios
- `04_Test_Cases/` – detailed test cases
- `05_Test_Data/` – test data
- `06_Test_Execution/` – actual execution results
- `07_Defect_Reports/` – defect log
- `08_RTM/` – requirement traceability matrix
- `09_Test_Summary/` – final summary
- `10_Screenshots/` – execution evidence

## Execution Integrity
The initial package intentionally does not fabricate live Pass/Fail results. Run the test cases in a browser and update `06_Test_Execution/Test_Execution.xlsx` with the observed Actual Result, Status, Bug ID and evidence.

## Suggested GitHub Evidence
For every failed test case, add a screenshot under `10_Screenshots/` using a meaningful filename such as:
`TC-CHECK-004_FAILED.png`

## Skills Demonstrated
Manual testing, test case design, positive/negative testing, regression testing, RTM, defect documentation, test reporting and GitHub documentation.
